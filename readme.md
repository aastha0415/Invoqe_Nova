# Nova – Smart Productivity Platform

A modern, responsive landing page for **Nova**, a smart productivity platform designed to help users organize their work, manage tasks, and achieve their goals efficiently.

## Live Demo

[Visit Nova Website](aastha0415.github.io/Invoqe_Nova/)

## About the Project

Nova is a responsive landing page developed as part of my Frontend Development Internship assignment.

The project focuses on creating a clean, modern, and user-friendly interface using HTML, CSS, and JavaScript.

It showcases the features and benefits of a productivity platform through different sections and interactive elements.

## Features

- Hero Section: Attractive introduction with a call-to-action button.
- Features Section: Highlights the key features of the platform.
- About Section: Provides information about Nova.
- Testimonials Section: Displays user feedback.
- Contact Section: Includes a contact form with frontend submission feedback.
- Responsive Design: Supports desktop, tablet, and mobile screens.
- Smooth Navigation: Smooth scrolling between website sections.
- Dark Mode: Allows users to switch between light and dark themes.
- Animations: Includes hover effects, transitions, and scroll reveal animations.

## Technologies Used

 HTML5 - Website structure 
 CSS3 - Styling, layouts, and responsiveness 
 JavaScript - Interactivity and functionality 
 Git & GitHub - Version control and project hosting 
 GitHub Pages - Website deployment 

## How to Run Locally

1. Clone this repository:

   --bash
   git clone https://github.com/aastha0415/Nova-Landing-Page.git

2. Open the project folder:

   --bash
   cd Nova-Landing-Page
   
3. Open `index.html` in your browser or use VS Code Live Server.
